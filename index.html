Features

Small editor, complete loop.

Everything from the first line to a finished executable — and nothing you have to install to get there.

Run with F5

Execute the current script in place. Output, errors and the exit code land in the built-in panel.

Build one .exe

The Build command embeds the X# interpreter, launcher, assets and icon into a single file.

Whole-folder projects

Add two lines of project properties and Build bundles the folder with its subfolders — art, sounds, data, everything.

Readable syntax

Keywords, strings and module calls are highlighted, so X# stays easy to scan while you work.

Examples that run

From loops and functions to a 2D platformer and a 3D FPS demo — open one, press F5, play.

No network, no telemetry

The editor never phones home. Write, run and build with the network unplugged.

Build

From project folder to one executable.

Mark the folder as a project, pick an icon, then hit Build. xCode writes one self-contained .exe — no installer, no runtime, no side files.

game.X# X# 
import graphics
import game

graphics.window(800, 600, "Neon Labyrinth")
graphics.addimage("hero")
game.addplayer("hero")
game.addphysics("hero")
game.player.speed = 5

game.player.controls
   {
      left  = game.input.key("a")
      right = game.input.key("d")
      jump  = game.input.key("space")
   }

while do for (inf)
   graphics.clear()
   graphics.text("A / D move, SPACE jump", 20, 20)
   graphics.update()
   time.wait(0.016)
endwhile
project properties asp 
-- asp = app setup properties
asp.connect(exe)             -- package this folder
asp.select.icon("icon.ico")  -- app icon
  • One format: exe — nothing else to choose.
  • Folder-aware: asp.connect(exe) ships the project folder and its subfolders.
  • Custom icon: .ico or .png up to 256×256. Skip it to keep the default.
  • Runs anywhere: the executable carries its own interpreter.

Install

Three steps, about a minute.

A per-user install with no administrator detour — unless Windows needs to add the .NET Framework first.

  1. 1

    Download the installer

    A single 132 MB .exe. Nothing else to fetch.

  2. 2

    Choose a scope

    Recommended adds optional Python, Node.js and .NET tools. xCode only installs the editor — Build works without them.

  3. 3

    Build something

    Launch xCode, open an example and press F5. Use File → Build… when you are ready to ship.

Installs to %LOCALAPPDATA%\Programs\xCode and adds xCode, source files and an uninstaller to the Start menu. Administrator rights are only requested if .NET Framework 4.8 must be installed.

FAQ

Questions, answered.

Windows says “Windows protected your PC”. Is this safe?

The executable is not code-signed, so SmartScreen treats a fresh download as unknown. Choose More info and then Run anyway. If you want certainty, compare the SHA-256 shown above with your local file: Get-FileHash .\xCodeSetup.exe -Algorithm SHA256.

Do I need Python or Node.js to use xCode?

No. The editor can run and build X# projects on its own. Python, PyInstaller, Node.js and .NET are only needed to rebuild xCode from source — that is what the Recommended scope and the portable tools are for.

Does Build need an internet connection?

No. Everything required to build an executable ships inside the editor, and the editor itself never makes network requests.

Where does it install, and how do I remove it?

By default to %LOCALAPPDATA%\Programs\xCode. Uninstall from Settings → Apps → xCode, from the Start menu (xCode → Uninstall), or run uninstall.exe --quiet. All files, shortcuts, registry entries and PATH additions are removed.

Can I install it for every user on the PC?

xCode installs per user, by design, so it never needs elevation. Administrator rights are only requested when the .NET Framework 4.8 installer has to run.

Is there a portable version?

Yes. The portable executable runs without installing anything — useful for a USB stick. Get it from the download section.

What exactly ends up inside a built executable?

The X# interpreter, the Windows launcher, your project files and the icon you chose. With asp.connect(exe) the whole project folder and its subfolders are included, so images, sounds and data files travel with the game.

What is X#?

X# (X Sharp) is a small interpreted language with .X# source files and built-in modules for console output, files, graphics, game physics, sound and math. It is designed to be readable and to put a playable window on screen in a few lines.
